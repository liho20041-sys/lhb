## 2. 特征

每条轨迹计算：
- `n` 点数、`path_ratio` 路径长/包围盒对角线
- `eff` 路径效率（首尾位移/路径长）
- `ext_ratio` 活动范围/对角线
- `hull_ratio` 凸包面积/对角线²
- `stopped` 静止段占比（段长 < 0.5% 对角线）
- `rev60/90/120` 方向反转次数、`fp25` 转角>25° 的特征点数
- `mean_ang/std_ang/maxang` 转角统计
- `eig_ratio` PCA 拉伸度

按标签均值（非徘徊 / 徘徊）：
| 特征 | 非徘徊 | 徘徊 |
|---|---|---|
| eff | 0.836 | **0.562** |
| stopped | 0.201 | **0.418** |
| path_ratio | 1.238 | 1.884 |
| rev120 | 2.791 | 4.387 |
| std_ang | 34.1 | 46.4 |

## 3. 规则（阈值在 train 标定）

规则：
```
pacing = eff<=0.6 & rev120>=1 & path_ratio>=0.8
dwell  = (ext_ratio<=0.3 & n>=20) | (stopped>=0.5)
loitering = pacing | dwell
```

## 4. 同特征机器学习上限（RandomForest）

- 训练/验证划分选 F1 最优概率阈值（0.26），在 test 上评估：

特征重要性（前六）：`eff 0.131、stopped 0.116、path_ratio 0.101、ext_ratio 0.096、mean_ang 0.088、std_ang 0.086`。

## 5. 结论

1. **规则 F1=0.521**，达到同特征 ML 上限（0.591）的约 **88%**——说明我们这套"路径效率 + 反转 + 静止"的规则方向是对的
2. 特征上，**路径效率、静止占比、路径长度比** 是最重要的三个信号，与生产规则使用的特征一致
3. 与摔倒评估不同，徘徊是**语义标签**，且该数据集是**热成像/俯视**，域差异大；不能期望可见光场景直接复现同样数值
4. 参考方法（rectangle / convex_hull / ellipse / closed_areas / no_motion）是针对该数据集设计的，理论上会更高；仓库未提供它们的预测 CSV，本次未复现其数字

## 6. 建议

1. **生产规则可复用**：把 `stopped`（静止占比）加入现有徘徊规则，比单纯的"路径效率+反转"更稳
2. **阈值按场景标定**：`eff<=0.6`、`stopped>=0.5` 是该数据集的最优操作点，不能直接照搬到可见光场景
3. 若要更高精度：用轨迹特征训练轻量分类器（RF/GBDT），或引入该数据集的特征工程
4. 最终仍以目标场景的 E 类回溯测试集为准
